# Calculator #

A simple and interactive calculator built using **HTML, CSS, and JavaScript**. The project provides basic arithmetic operations through a clean user interface and also supports keyboard input.

# Features #

* Basic arithmetic operations:
                              * Addition
                              * Subtraction
                              * Multiplication
                              * Division
                              * Percentage calculation
                              * Decimal number support
                              * Backspace functionality
                              * Clear all functionality
                              * Calculation history display
                              * Operator highlighting
                              * Keyboard support
                              * Error handling for division by zero
                              * Responsive and simple user interface
                              * Theme button support

# Technologies Used #

* HTML5 – Structure of the calculator
* CSS3 – Styling and layout
* JavaScript – Calculator logic and user interaction

# How It Works #

The calculator uses JavaScript to handle user input and perform arithmetic operations.

When a number is selected, it is displayed on the calculator screen. When an operator is selected, the first number and operator are stored. The second number is then entered and the result is calculated when the `=` button is pressed.

The calculator also maintains an operation history above the main display.

# Supported Operations #

| Operation      | Symbol |
| -------------- | ------ |
| Addition       | `+`    |
| Subtraction    | `-`    |
| Multiplication | `×`    |
| Division       | `÷`    |
| Percentage     | `%`    |

# Keyboard Support #

The calculator can also be operated using the keyboard.

| Key                 | Function          |
| ------------------- | ----------------- |
| `0-9`               | Enter numbers     |
| `+`                 | Addition          |
| `-`                 | Subtraction       |
| `*`                 | Multiplication    |
| `/`                 | Division          |
| `.`                 | Decimal           |
| `Enter`             | Calculate result  |
| `Backspace`         | Delete last digit |
| `Delete` / `Escape` | Clear calculator  |
| `%`                 | Percentage        |

# Example #

For example: 25 + 15 = 40

The calculator displays the operation in the history section and shows the final result on the main display.

# Error Handling #

The calculator prevents invalid division by zero operations and displays: Error

The calculator can then be cleared to start a new calculation.
